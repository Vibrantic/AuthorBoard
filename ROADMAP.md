# 🗺️ AuthorBoard Roadmap

Welcome to the development roadmap for **AuthorBoard**! This document outlines planned features, enhancements, and ideas currently in the pipeline. 

> [!NOTE]  
> Items listed here are prioritized based on project needs and community feedback, and may be implemented in no particular order.

---

## 🚀 Planned Features & Enhancements

### 🎨 UI & Layout Controls
- [ ] **Reset Note Size**  
  - Quick option to restore standard dimensions for notes.
- [ ] **Grid Snapping on Resize**  
  - Align notes and groups dynamically to the grid during resize actions (active when grid snapping is enabled).
- [ ] **Ribbon Editing Bar**  
  - Unified contextual ribbon bar containing editing tools for notes, pins, and groups.

### 📝 Content & Media
- [ ] **Simple Text Block**  
  - Lightweight plain-text element for quick annotation and minimal formatting needs.
- [ ] **Custom Stamp Library**  
  - Support for selecting and placing custom stamps directly from a built-in library.
