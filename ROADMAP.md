# 🗺️ AuthorBoard Roadmap

Welcome to the development roadmap for **AuthorBoard**! This document outlines planned features, enhancements, and bug fixes currently in the pipeline.

> [!NOTE]
> Items listed here are prioritized based on project needs and community feedback, and may be implemented in no particular order.

---

## 🚀 Planned Features & Enhancements

### ⚙️ Usability & Workflows
- [ ] **Additional Keyboard Shortcuts**  
  - Add a shortcut for pin and group locking/unlocking.
- [ ] **Customizable Keybindings**  
  - Allow users to configure and edit custom shortcuts via the Settings menu.
- [ ] **Group Ordering (Z-Index)**  
  - Add options to send groups to the back or bring them to the front.
- [ ] **Nested Grouping**  
  - Enable grouping existing groups together via the context menu (right-click).

### 🎨 UI & Layout Controls
- [ ] **Reset Note Size**  
  - Quick option to restore standard dimensions for notes.
- [ ] **Grid Snapping on Resize**  
  - Align notes and groups dynamically to the grid during resize actions when grid snapping is active.
- [ ] **Ribbon Editing Bar**  
  - Unified contextual ribbon bar containing editing tools for notes, pins, and groups.
- [ ] **UI Rework**  
  - Streamline interface for improved readability and replace text labels with intuitive icons.
- [ ] **Statistics Dashboard Overhaul**  
  - Optimize data tracking and present board statistics in a cleaner, more visual layout.

### 📝 Content, Media & Themes
- [ ] **Simple Text Block**  
  - Lightweight plain-text element for quick annotations and minimal formatting needs.
- [ ] **Custom Stamp Library**  
  - Support selecting and placing custom stamps directly from a built-in library.
- [ ] **UI Theme Customization**  
  - Support for custom user themes and color schemes.
- [ ] **Project Templates**  
  - Starter board templates for faster setup.
- [ ] **Note & Group Templates**  
  - Specialized templates tailored for story arcs, character profiles, world-building, etc.

---

## 🐛 Fixes & Refinements

### 📦 Grouping System Rework
- [ ] **Revise & Refactor Grouping Logic**  
  - Overall code and behavior cleanup for nested elements.
- [ ] **Locked Element Parent Movement**  
  - Ensure locked sub-groups move seamlessly with their parent group.
  - Ensure locked notes inside a group move when the parent group is moved.
- [ ] **Visual Hierarchy Indicator**  
  - Display an ordering index badge (e.g., `1` for top-level, `2` for inner level) in the bottom-left corner of nested groups.
