# Internationalisation

## Principle: the German text is the key

```python
label = tr("Neues Notizbuch")                  # lookup in the active language table
text  = tr("{n} Bücher", n=3)                  # placeholders are filled with str.format
ATTRIBUTE_SUGGESTIONS = [N_("Datum"), ...]     # N_ only *marks* a text for extraction
menu.addAction(tr(name))                       # translate where it is displayed
```

* `i18n.tr(text, **kw)` returns `table.get(text) or text`: **a missing translation falls back to German**.
* `locales/<code>.json` is `{"_name": "English", "German text": "translation", ...}`.
* `de.json` only contains `_name`; German needs no table.
* `N_()` returns its argument. Use it for texts in module-level data (note type names, status names, preset colours ...) because `tr()` at import time would use the wrong language. Translate them where they are shown.

!!! warning "Not at import time"
    The language can change while the program runs (a new `MainWindow` is created). Never call `tr()` in module-level constants; build translated objects in functions (`builtin_note_types()`).

## Tooling

```bash
python i18n.py new fr "Français"   # creates locales/fr.json with every key (empty values)
python i18n.py update fr           # adds keys that appeared later
python i18n.py check fr            # lists untranslated keys
```

`extract_keys()` parses all `*.py` files with `ast` and collects the first argument of every `tr(...)` / `N_(...)` call, so implicit string concatenation and multi-line strings work.

## Language-independent data

Some *data* contains translated words - e.g. attribute names created from a note type. The code that **reads** these must understand every language: see `models.attribute_matches()` for *Date / Time / Number*.

## Help texts

`help/<code>/NN-topic.md`. `HelpDialog` loads the folder of the active language and falls back to `help/en`. Topics link to each other with `[text](topic:NN-name)`.

## Qt's own texts

`main.install_qt_translation` installs Qt's `qtbase_<code>` translator (file dialogs, colour dialog buttons) when the Qt installation provides it.
