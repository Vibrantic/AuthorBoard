# Comments

Comments let you annotate words or sentences without changing the text, like review comments in a word processor.

## Adding a comment

1. **Select** the word or sentence (in the Inspector text or in the full-size editor). Without a selection the word under the pointer is used.
2. **Right-click → Add comment …** (or Ctrl+Alt+M in the editor).
3. Type the comment and confirm.

The commented text gets a faint amber background with a dashed underline.

## Reading, editing, deleting

- **Hover** the marked text: the comment pops up.
- **Right-click** the marked text: *Edit comment …* or *Delete comment*.
- If you delete the commented words, the comment disappears with them.

## The Comments tab

In the right dock switch between **Inspector** and **Comments**. The tab shows how many comments the notebook has.

- The list shows every comment: note title, the commented words and the comment text.
- **Double-click** a comment (or press *Go to location*): the note opens in the full-size editor and the **commented words are selected**.
- **Delete** a comment with the button or the Delete key. This also removes the marker from the text.
- Use the search box to filter by note title, quoted text or comment text.

Notes with comments show a speech-bubble badge with the count. Comments are stored in the notebook file and can be undone with Ctrl+Z.
