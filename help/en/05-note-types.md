# Note types

Every note has a **type**. The type decides the colour of the note and which attributes a new note starts with.

## Built-in types

| Type | Suggested attributes |
|---|---|
| Note | – |
| Character | Age, Role, Occupation |
| Place | Region, Type |
| Chapter | Number, Status, Word count |
| Scene | Date, Time, Place, Perspective |
| Event | Date, Time, Place |
| Plot | Act, Status |
| Item | Owner, Origin |
| Idea | – |
| Research | Source, Link |

Notes with the attribute **Number** are sorted by it in the manuscript export and in *Arrange by note type*.

## Your own note types

There are two kinds:

- **Book note types** exist only in the open notebook.
- **Global note types** are available in every notebook.

Manage both in **Edit → Settings … → Note types**:

1. Choose the tab *Note types – this book* or *Note types – all books*.
2. Click **＋ Note type**, enter the name, pick a colour and list the attributes (comma separated) that new notes of this type should get.
3. Press *Apply*.

A type that is still used by notes cannot be deleted; change those notes first.

**Quick way:** press Shift+Space, type a name that does not exist and choose *Create new note type* - this creates a book note type.

A notebook remembers the global types its notes use, so it still looks right when you open it on another computer.
