# Export

All exports are in the **File → Export** menu.

## Manuscript

Turns your chapters and scenes into a readable manuscript.

1. Choose which **note types** go in (default: Chapter and Scene).
2. The order follows the attribute **Number** (`1`, `1.1`, `1.2`, `2` …), then the title.
3. Choose the format: **Markdown, Text, HTML or PDF**, and whether titles become headings.

In **HTML and PDF** the formatting of the notes (bold, colours, fonts …) and the **images** are kept. Markdown and text contain the plain text.

## Outline as Markdown

One Markdown file with all notes grouped by type, including attributes, tags, status and connections.

## Board as image

Saves the whole board as a PNG picture.

## Copies and imports

*File → Save a copy as …* writes a complete notebook file (with attachments). *Import …* on the bookshelf reads such files back.
