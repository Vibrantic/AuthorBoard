# Search and filters

The **Notes** panel on the left searches the whole notebook.

## Search box (Ctrl+F)

- Searches **title, content, tags, attributes and note type**.
- Several words must **all** appear somewhere in the note.
- Type `#magic` to look for the tag *magic*.

## Filters

- **Note type** - only notes of one type.
- **Tag** - only notes with this tag.
- **Status** - draft, revise or done.

Notes that do not match are **dimmed** on the board (and their threads too); the tree below lists only the matches, grouped by type, with a counter *x of y notes*. Click an entry to select the note and centre the board on it.

## Other searches

- The shelf search filters notebooks.
- The Inspector's connection list has its own search and filters.
- The Comments tab searches comments.
- This documentation window searches all chapters.
