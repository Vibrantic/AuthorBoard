# Locking and focus mode

## Locking notes

A **locked note stays in place**: it cannot be dragged or resized. It shows a small padlock.

- Press **Ctrl+L** with notes selected (locks them; if all are already locked, unlocks them).
- Or use the context menu *Lock note / Unlock note*, or the **Lock position** box in the Inspector.
- *Arrange by note type* and *Snap to grid* leave locked notes alone.

## Locking pins

Right-click a pin → **Lock pin / Unlock pin**. A locked pin cannot be dragged inside its note (it shows a keyhole) but it **still moves with the note** when the note is moved, and its threads follow as usual.

## Focus mode

When a note is selected, AuthorBoard **greys out everything that is not connected to it**: only the selected note, the notes directly connected to it by threads, and the threads touching it stay fully visible. Click the empty board to see everything again.

- Turn it on or off in **View → Focus mode** or in *Settings*.
- It works together with the search filter: items that do not match the search are dimmed even more.

## Threads in front

Threads are drawn **in front of the notes**, but fainter where they cross a note, so you can follow a connection across the board without losing the note text.
