# Notebooks

## Notebook information

Open it with **File → Notebook info …** (or *Edit info …* on the shelf). You can set:

| Field | Meaning |
|---|---|
| Title / Author / Genre | Shown on the shelf and used in exports |
| Category | The shelf the book stands on |
| Colour | Colour of the book spine |
| Word goal | Target word count; drives the green progress bar |
| Deadline | Free text, for example a date |
| Description | Blurb, premise or idea |
| Custom fields | Any name/value pairs: working title, series, editor … |

## Word goal and daily progress

The status bar at the bottom right shows `notes · words · Goal x % · Today +n`. *Today* is the number of words written since the first time you opened the book today.

## Saving

- **Ctrl+S** saves the notebook inside the library.
- **Save a copy as …** (Ctrl+Shift+S) writes a separate `.json` file; the book stays in the library.
- A notebook is **one self-contained file**: notes, pins, threads, comments, attachments and tag memory are all inside.
- When you leave a book with unsaved changes, AuthorBoard asks whether to save, discard or cancel.
