# Keyboard shortcuts

## General

| Shortcut | Action |
|---|---|
| Ctrl+B | Back to the bookshelf |
| Ctrl+N | New notebook |
| Ctrl+O | Open a board file |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save a copy as … |
| Ctrl+Q | Quit |
| Ctrl+Z / Ctrl+Y | Undo / Redo (also Ctrl+Shift+Z) |
| Ctrl+, | Settings |
| F1 | Documentation |

## Board

| Shortcut | Action |
|---|---|
| Shift+Space | Find a note type and create a note |
| Double-click board | New note |
| Double-click note | Add a pin |
| Right-drag pin → pin | Connect with a thread |
| Middle mouse drag | Pan |
| Mouse wheel | Zoom |
| Ctrl+0 / Ctrl+1 | Show all / 100 % zoom |
| Ctrl+D | Duplicate note |
| Ctrl+L | Lock / unlock selected notes |
| Ctrl+F | Search |
| F2 | Open the full-size editor |
| Ctrl+I | Statistics |
| Delete | Delete selection |

## Full-size editor

| Shortcut | Action |
|---|---|
| Ctrl+B / I / U | Bold / italic / underline |
| Ctrl+K | Insert link |
| Ctrl+Alt+M | Add comment |
| Ctrl+click on link | Open in the web browser |
| F11 | Full screen |
