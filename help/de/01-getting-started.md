# Erste Schritte

**AuthorBoard** ist ein Notizbuch für Autorinnen und Autoren. Jedes *Buch*, an dem du schreibst, ist ein Notizbuch und steht in einem **Bücherregal**. In einem Notizbuch arbeitest du auf einem **Board**: einer Korkwand mit Post-its, Pins und Fäden – dazu Zeitleiste, Rich-Text-Editor, Kommentare und Anhänge.

## Installation

1. Python 3.10 oder neuer installieren.
2. Abhängigkeiten installieren: `pip install -r requirements.txt` (PySide6 und das optionale pyspellchecker).
3. Programm starten: `python main.py`.

## Dein erstes Notizbuch in fünf Minuten

1. Auf der Startseite (dem Bücherregal) auf **＋ Notizbuch** klicken, einen Titel eingeben und *Erstellen* drücken. Das Board öffnet sich.
2. **Doppelklick auf das leere Board** legt eine Notiz an – oder **Shift+Leertaste** drücken und eine Notizart wie *Charakter* oder *Kapitel* wählen.
3. Notiz auswählen und rechts im **Inspector** Titel, Tags, Attribute und Text eintragen.
4. **Doppelklick auf eine Notiz** öffnet den großen Editor. 
5. Rechtsklick pin setzen. Eine zweite Notiz mit Pin anlegen, dann die **rechte Maustaste** auf einem Pin gedrückt halten und zum anderen Pin ziehen. Ein Faden verbindet beide. Rechtsklick auf den Faden: Beschriftung wie „Bruder von“.
6. **Strg+S** speichert, **Strg+B** führt zurück ins Bücherregal.
