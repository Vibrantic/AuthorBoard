# Der große Editor

Öffnen mit **F2**, der Schaltfläche *Im großen Editor öffnen* im Inspector oder *Im großen Editor öffnen* im Kontextmenü einer Notiz.

## Formatierungsleiste

| Element | Funktion |
|---|---|
| Schriftart, Größe | Schriftfamilie und -größe |
| **B** *I* U S | Fett (Strg+B), kursiv (Strg+I), unterstrichen (Strg+U), durchgestrichen |
| **A** | Textfarbe – Schnellfarben, eigene Farbe oder *Standardfarbe* |
| Marker | **Hintergrundfarbe** hinter dem Text – Schnellfarben, eigene Farbe oder *Markierung entfernen* |
| Ausrichtung | Links, zentriert, rechts, Blocksatz |
| • | Aufzählung ein/aus |
| 🔗 | **Link** einfügen (Strg+K) |
| 🖼 | **Bild** einfügen |
| 💬 | **Kommentar** hinzufügen (Strg+Alt+M) |
| ⌫ | Formatierung der Markierung entfernen |
| Rechtschreibung | Wörterbuch: Automatisch / English / Deutsch / Aus |

Ohne Markierung wirkt die Formatierung auf das Wort unter dem Cursor.

## Links

Text markieren, **Strg+K** drücken und die Adresse eingeben. **Strg+Klick** auf einen Link öffnet ihn im **Webbrowser**; beim Daraufzeigen siehst du die Adresse. Rechtsklick auf einen Link: *Link im Browser öffnen*. Es werden nur `http`, `https`, `mailto` und `ftp` geöffnet.

## Bilder

Über die Bild-Schaltfläche, per **Einfügen** aus der Zwischenablage (Strg+V) oder indem du eine Bilddatei in den Text **ziehst**. Jedes Bild wird als Anhang der Notiz gespeichert und steckt damit in der Notizbuch-Datei.

## Rechtschreibprüfung

Unbekannte Wörter erhalten eine **rote Wellenlinie**. Rechtsklick auf ein Wort: Vorschläge, *Zum Wörterbuch hinzufügen* oder *Ignorieren*. Notiztitel und Tags des geöffneten Buchs werden nie markiert. Unterstützt sind Englisch und Deutsch; die Sprache wählst du in der Leiste oder in den *Einstellungen*. Die Prüfung braucht das optionale Paket `pyspellchecker`.

## Kommentar-Seitenleiste und Abschluss

Die Seitenleiste listet die Kommentare dieser Notiz ([mehr](topic:08-comments)). **F11** schaltet den Vollbildmodus um. *Übernehmen* speichert die Arbeit in der Notiz, *Abbrechen* verwirft sie. Wort- und Zeichenzahl stehen unter dem Text.
