# Notizarten

Jede Notiz hat eine **Art**. Die Art bestimmt die Farbe der Notiz und welche Attribute eine neue Notiz bekommt.

## Eingebaute Arten

| Art | Vorgeschlagene Attribute |
|---|---|
| Notiz | – |
| Charakter | Alter, Rolle, Beruf |
| Ort | Region, Typ |
| Kapitel | Nummer, Status, Wortzahl |
| Szene | Datum, Uhrzeit, Ort, Perspektive |
| Ereignis | Datum, Uhrzeit, Ort |
| Handlung | Akt, Status |
| Gegenstand | Besitzer, Herkunft |
| Idee | – |
| Recherche | Quelle, Link |

Notizen mit dem Attribut **Nummer** werden danach im Manuskript-Export und bei *Nach Notizart anordnen* sortiert.

## Eigene Notizarten

Es gibt zwei Sorten:

- **Buch-Notizarten** existieren nur im geöffneten Notizbuch.
- **Globale Notizarten** stehen in jedem Notizbuch zur Verfügung.

Beide verwaltest du unter **Bearbeiten → Einstellungen … → Notizarten**:

1. Reiter *Notizarten – dieses Buch* oder *Notizarten – alle Bücher* wählen.
2. **＋ Notizart** klicken, Namen eingeben, Farbe wählen und die Attribute (mit Komma getrennt) angeben, die neue Notizen dieser Art bekommen sollen.
3. *Übernehmen* drücken.

Eine Art, die noch von Notizen benutzt wird, lässt sich nicht löschen – ändere zuerst diese Notizen.

**Schneller Weg:** Shift+Leertaste drücken, einen noch nicht vorhandenen Namen tippen und *Neue Notizart anlegen* wählen – das erzeugt eine Buch-Notizart.

Ein Notizbuch merkt sich die globalen Arten, die seine Notizen benutzen – es sieht also auch auf einem anderen Computer richtig aus.
