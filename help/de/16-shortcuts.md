# Tastenkürzel

## Allgemein

| Kürzel | Aktion |
|---|---|
| Strg+B | Zurück zum Bücherregal |
| Strg+N | Neues Notizbuch |
| Strg+O | Board-Datei öffnen |
| Strg+S | Speichern |
| Strg+Umschalt+S | Kopie speichern unter … |
| Strg+Q | Beenden |
| Strg+Z / Strg+Y | Rückgängig / Wiederholen (auch Strg+Umschalt+Z) |
| Strg+, | Einstellungen |
| F1 | Dokumentation |

## Board

| Kürzel | Aktion |
|---|---|
| Shift+Leertaste | Notizart suchen und Notiz anlegen |
| Doppelklick auf Board | Neue Notiz |
| Doppelklick auf Notiz | Großen Editor öffnen |
| Rechts ziehen Pin → Pin | Mit Faden verbinden |
| Mittlere Maustaste ziehen | Verschieben |
| Mausrad | Zoomen |
| Strg+0 / Strg+1 | Alles anzeigen / 100 % |
| Strg+D | Notiz duplizieren |
| Strg+L | Ausgewählte Notizen sperren / entsperren |
| Strg+F | Suche |
| F2 | Großen Editor öffnen |
| Strg+I | Statistik |
| Entf | Auswahl löschen |

## Großer Editor

| Kürzel | Aktion |
|---|---|
| Strg+B / I / U | Fett / kursiv / unterstrichen |
| Strg+K | Link einfügen |
| Strg+Alt+M | Kommentar hinzufügen |
| Strg+Klick auf Link | Im Webbrowser öffnen |
| F11 | Vollbild |
