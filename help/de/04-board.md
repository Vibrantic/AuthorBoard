# Arbeiten auf dem Board

## Navigieren

| Aktion | So geht's |
|---|---|
| Zoomen | Mausrad (zoomt zum Mauszeiger) |
| Verschieben | **Mittlere Maustaste** gedrückt halten und ziehen |
| Mehrere Notizen wählen | Rechteck auf dem leeren Board aufziehen |
| Alles anzeigen | **Strg+0** (*Alles anzeigen*), 100 % Zoom: Strg+1 |

## Notizen

- **Anlegen:** Doppelklick auf das leere Board, **Shift+Leertaste** (Notizart-Suche), **＋ Notiz** in der Werkzeugleiste oder Rechtsklick auf das Board → *Neue Notiz hier*.
- **Verschieben** per Ziehen, **Größe ändern** an der umgeknickten Ecke unten rechts.
- **Duplizieren** mit Strg+D (kopiert Text, Attribute, Pins, Anhänge und Kommentare, aber keine Fäden).
- **Löschen** mit der Entf-Taste oder dem Kontextmenü.
- Über einer Notiz zeigt ein Tooltip Titel, Art, Attribute, Tags und Wortzahl.
- *Am Raster ausrichten* (Ansicht) lässt Notizen beim Verschieben einrasten. *Nach Notizart anordnen* sortiert Notizen in Spalten (gesperrte Notizen bleiben stehen).

## Pins

- **Doppelklick auf eine Notiz** setzt einen Pin an dieser Stelle. Ziehe einen Pin, um ihn in der Notiz zu verschieben.
- **Rechtsklick auf einen Pin**: Farbe ändern, Fäden entfernen, **sperren / entsperren** oder löschen.
- Ein **gesperrter Pin** lässt sich in der Notiz nicht mehr ziehen (kleines Schlüsselloch), **wandert aber weiter mit seiner Notiz**.

## Fäden

- **Zwei Pins verbinden:** die **rechte Maustaste** auf einem Pin gedrückt halten, zu einem anderen Pin ziehen und loslassen.
- **Rechtsklick auf einen Faden:** Farbe, Beschriftung (z. B. „Bruder von“) und Löschen.
- Fäden liegen **vor den Notizen**. Wo ein Faden eine Notiz kreuzt, ist er blasser gezeichnet, damit der Text lesbar bleibt. Die Pinköpfe liegen immer obenauf.

## Fokus-Modus

Wählst du eine Notiz aus, werden Notizen und Fäden, die **nicht mit ihr verbunden** sind, ausgegraut. Siehe [Sperren und Fokus-Modus](topic:09-locking-focus).
